# ClinIQ

[![CI](https://github.com/sathiakhadija/ClinIQ/actions/workflows/ci.yml/badge.svg)](https://github.com/sathiakhadija/ClinIQ/actions/workflows/ci.yml)

**Intelligent NHS Clinical Guidelines Assistant**

ClinIQ is a Retrieval-Augmented Generation (RAG) system that lets healthcare professionals and patients query NHS clinical guidelines in natural language and receive sourced, accurate answers.

## Architecture

ClinIQ follows a three-stage pipeline:

**Ingestion (run once):**
1. Load NHS NICE guideline PDFs
2. Split into 500-token chunks with 50-token overlap
3. Embed with text-embedding-3-small
4. Store in ChromaDB with source metadata

**Query (real-time):**
1. Embed the user question
2. Retrieve top-5 most similar chunks from ChromaDB
3. Build structured prompt with context and citations
4. Generate answer with GPT-4o-mini
5. Return answer with guideline citations

---

## Evaluation

Evaluated using RAGAS across four metrics:

| Metric | What it measures |
|---|---|
| Faithfulness | Is the answer grounded in the retrieved context? |
| Answer Relevancy | Does the answer address the question asked? |
| Context Precision | Are the retrieved chunks relevant to the question? |
| Context Recall | Does the retrieved context cover what is needed? |

Evaluation runs logged to [W&B Weave](https://wandb.ai/sathiakhadija/cliniq).

## Local Setup

### Prerequisites

- Python 3.12
- pip or conda
- OpenAI API key (from https://platform.openai.com/api-keys)
- Weights & Biases account (optional, for experiment tracking)

### Installation

**1. Clone repository:**
```bash
git clone https://github.com/sathiakhadija/ClinIQ.git
cd ClinIQ
```

**2. Create virtual environment:**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

**3. Install dependencies:**
```bash
pip install -r requirements.txt
```

**4. Configure environment:**
```bash
cp .env.example .env
# Edit .env and add your API keys:
# OPENAI_API_KEY=sk-...
# WANDB_API_KEY=... (optional)
```

**5. Download NHS guidelines:**
Place these official NICE PDFs in `data/nhs_docs/`:

| Guideline | PDF |
|---|---|
| Hypertension in adults (NG136) | https://www.nice.org.uk/guidance/ng136/resources/hypertension-in-adults-diagnosis-and-management-pdf-66141722710213 |
| Type 2 diabetes in adults (NG28) | https://www.nice.org.uk/guidance/ng28/resources/type-2-diabetes-in-adults-management-pdf-1837338615493 |
| Depression in adults (NG222) | https://www.nice.org.uk/guidance/ng222/resources/depression-in-adults-treatment-and-management-pdf-66143832307909 |
| Chronic kidney disease (NG203) | https://www.nice.org.uk/guidance/ng203/resources/chronic-kidney-disease-assessment-and-management-pdf-66143713055173 |
| Asthma, replacing retired NG80 (NG245) | https://www.nice.org.uk/guidance/ng245/resources/asthma-diagnosis-monitoring-and-chronic-asthma-management-bts-nice-sign-pdf-66143958279109 |

**6. Ingest guidelines:**
```bash
python ingest.py
```

This creates a ChromaDB index in `data/chroma/`

**7. Run the app:**
```bash
streamlit run app.py
```

Visit http://localhost:8501 in your browser.

## Evaluation

Run RAGAS evaluation on 10 test questions:

```bash
python evaluate.py
```

Results are saved to `evaluation_results.json` and logged to W&B Weave.

## Limitations and Future Work

**Current limitations:**
- Limited to NHS NICE guidelines (no other sources)
- Requires manual PDF upload (no automated scraping)
- No persistent chat history (session-based only)
- No user authentication or multi-tenancy

**Future improvements:**
- [ ] Automated guideline scraping from NHS website
- [ ] Database-backed chat history
- [ ] Fine-tuned embedding model for medical text
- [ ] Multi-turn reasoning (follow-up questions preserve context)
- [ ] Guideline version tracking and update notifications
- [ ] User feedback collection and model improvement
